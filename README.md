# Yarn shop — интернет-магазин пряжи

Учебный проект: вёрстка интернет-магазина на чистых HTML, CSS и JavaScript
(без CSS/JS-фреймворков).

## Структура проекта

```
├── index.html          — перенаправление на страницу каталога
├── README.md
├── images/             — изображения, логотип, favicon
├── css/                — стили
│   ├── style.css       — каталог (главная страница)
│   ├── cart.css        — корзина
│   └── main.css        — страница доставки
├── js/                 — скрипты
│   ├── data.js         — данные товаров (отдельный файл данных)
│   ├── script.js       — каталог: карточки, добавление в корзину
│   ├── cart.js         — корзина: количество, суммы, форма заказа
│   └── main.js         — страница доставки
└── pages/              — HTML-страницы
    ├── index.html      — каталог
    ├── cart/           — корзина и оформление заказа
    └── main/           — страница доставки
```

## Страницы и возможности

- **Каталог** (`pages/index.html`): карточки товаров из `js/data.js`,
  всплывающее окно с описанием по кнопке «Подробнее», добавление в корзину
  кнопкой и перетаскиванием, счётчик товаров в шапке, кнопка «Оформить заказ».
- **Корзина** (`pages/cart/cart.html`): изменение количества (−/+),
  удаление позиций, автоматический пересчёт итоговой суммы, хранение корзины
  в `localStorage`, форма заказа (имя, фамилия, телефон, адрес доставки,
  тип оплаты, пункт выдачи) с валидацией, по кнопке «Создать заказ»
  показывается сообщение «Заказ создан!».
- **Доставка** (`pages/main/main.html`): форма оформления доставки.

## Адаптивность

Медиазапросы для ноутбука, планшета и телефона: сетка каталога перестраивается,
таблица корзины складывается в колонку, шапка и кнопки масштабируются.

## Запуск

Открыть `index.html` в браузере либо раздать корень проекта статическим
сервером, например:

```bash
python -m http.server 8000
```

и перейти на `http://localhost:8000/`.

## Деплой на GitHub Pages

Проект — статический сайт, деплой настроен через GitHub Actions
(`.github/workflows/deploy.yml`).

1. Запушьте проект в ветку `main`:
   ```bash
   git add .
   git commit -m "Add deploy"
   git push origin main
   ```
2. В репозитории откройте **Settings → Pages** и в поле **Source**
   выберите **GitHub Actions**.
3. После выполнения workflow сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/web-store-frontend/`.

Корневой `index.html` перенаправляет на страницу каталога `pages/index.html`,
поэтому деплоить нужно весь проект целиком (как настроено в workflow).
